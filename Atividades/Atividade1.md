# 🕒 Linha do Tempo da Evolução dos Sistemas Operacionais

---

## 🖥️ Década de 1950

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **1956** | **GM-NAA I/O** | Considerado o primeiro sistema operacional desenvolvido para computadores IBM. |
| **1959** | **SHARE Operating System (SOS)** | Sistema criado pela comunidade SHARE para facilitar o uso dos computadores IBM. |

---

## 🖥️ Década de 1960

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **1961** | **CTSS** | Primeiro sistema operacional com suporte a tempo compartilhado (*Time Sharing*). |
| **1964** | **IBM OS/360** | Sistema desenvolvido para a linha de computadores IBM System/360. |
| **1969** | **UNIX** | Criado nos laboratórios Bell Labs, tornou-se base para diversos sistemas modernos. |

---

## 🖥️ Década de 1970

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **1974** | **CP/M** | Muito utilizado em microcomputadores da época. |
| **1977** | **BSD Unix** | Variante do UNIX desenvolvida pela Universidade da Califórnia (Berkeley). |

---

## 🖥️ Década de 1980

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **1981** | **MS-DOS** | Sistema operacional da Microsoft para computadores IBM PC. |
| **1984** | **Mac OS (System 1)** | Primeiro sistema gráfico lançado pela Apple. |
| **1985** | **Windows 1.0** | Primeira versão do Microsoft Windows com interface gráfica. |
| **1987** | **OS/2** | Desenvolvido em parceria entre IBM e Microsoft. |

---

## 🖥️ Década de 1990

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **1991** | **Linux** | Criado por Linus Torvalds, tornou-se um dos sistemas mais utilizados no mundo. |
| **1993** | **Windows NT** | Introduziu uma nova arquitetura para os sistemas da Microsoft. |
| **1995** | **Windows 95** | Popularizou a interface gráfica moderna e o Menu Iniciar. |
| **1998** | **Windows 98** | Evolução do Windows 95 com melhor suporte a hardware. |
| **1999** | **Mac OS 9** | Última versão da família clássica do Mac OS. |

---

## 🖥️ Década de 2000

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **2001** | **Mac OS X** | Sistema baseado em UNIX, marcando uma nova geração dos computadores Apple. |
| **2001** | **Windows XP** | Um dos sistemas operacionais mais populares da Microsoft. |
| **2007** | **iOS** | Sistema operacional criado para o iPhone. |
| **2008** | **Android** | Sistema operacional móvel desenvolvido pelo Google. |
| **2009** | **Windows 7** | Destacou-se pela estabilidade e desempenho. |

---

## 🖥️ Década de 2010

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **2012** | **Windows 8** | Introduziu uma interface voltada para dispositivos com tela sensível ao toque. |
| **2013** | **SteamOS** | Sistema baseado em Linux voltado para jogos. |
| **2015** | **Windows 10** | Unificou recursos das versões anteriores e trouxe atualizações contínuas. |
| **2010–2019** | **Distribuições Linux** | Consolidação de distribuições como Ubuntu, Fedora e Debian, além da evolução do Android e iOS. |

---

## 🖥️ Década de 2020

| Ano | Sistema Operacional | Descrição |
|:---:|---------------------|-----------|
| **2020** | **macOS Big Sur** | Modernização da interface e otimizações para os processadores Apple Silicon. |
| **2021** | **Windows 11** | Nova interface, melhorias de desempenho e foco em produtividade. |
| **2020–Atualidade** | **Android, iOS e Linux** | Evolução contínua com foco em segurança, inteligência artificial e computação em nuvem. |

---

## 📌 Resumo da Evolução

```text
1950 ─ GM-NAA I/O
      │
1960 ─ CTSS ─ IBM OS/360 ─ UNIX
      │
1970 ─ CP/M ─ BSD Unix
      │
1980 ─ MS-DOS ─ Mac OS ─ Windows 1.0 ─ OS/2
      │
1990 ─ Linux ─ Windows NT ─ Windows 95 ─ Windows 98
      │
2000 ─ Mac OS X ─ Windows XP ─ iOS ─ Android ─ Windows 7
      │
2010 ─ Windows 8 ─ SteamOS ─ Windows 10
      │
2020 ─ macOS Big Sur ─ Windows 11 ─ Android/iOS/Linux
```
